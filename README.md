# Ab. Sofía Segura Santana — Estudio Jurídico Especializado

Sitio web oficial y plataforma digital para el **Estudio Jurídico Ab. Sofía Segura Santana**, especializada en **Derecho Penal, Tránsito, Derecho Familiar y Laboral**.

## ⚖️ Áreas de Práctica & Litigio
- **Derecho Penal & Delitos Complejos:** Defensa técnica en robo, receptación, estafa, secuestro extorsivo, asociación ilícita y delincuencia organizada.
- **Flagrancias 24/7:** Intervención jurídica urgente ante Fiscalía y Unidades Judiciales.
- **Materia de Tránsito:** Accidentes, siniestros viales, peritajes mecánicos e impugnaciones.
- **Compañías de Transporte:** Constitución, legalización y trámites de operadoras ante la ANT y GADs.
- **Derecho Familiar:** Pensiones de alimentos, régimen de visitas, tenencia y divorcios.
- **Derecho Laboral:** Despidos intempestivos, vistos buenos, actas de finiquito y liquidaciones.

## 🚀 Tecnologías
- **React 18** + **TypeScript**
- **Vite** para compilación ultrarrápida
- **Tailwind CSS** para maquetación editorial responsiva
- **Lucide React** para iconografía
- **Firebase Hosting** + **GitHub Actions** (CI/CD continuo)

## 🛠️ Instalación y Desarrollo Local
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```

## 🌐 Despliegue en Firebase Hosting
El proyecto cuenta con integración continua configurada en `.github/workflows/firebase-deploy.yml`:
- Cada `push` a la rama `main` ejecuta la compilación y despliegue automático a Firebase Hosting.
